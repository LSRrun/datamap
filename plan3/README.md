# 东鹏数据地图 Demo

这是一个纯静态单页 Demo，数据来自 `数据模型全.xlsx` 的“模型目录”工作表。

## 使用方式

直接双击 `index.html` 即可浏览。也可以在当前目录启动本地服务器：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 功能

- L1 → L2 → L3 → L4 四级可展开目录树
- 带层级连线的真实数据表粒子分布图
- 点击一级主题域自动居中聚焦并隐藏其他主题域
- 拖拽平移、滚轮/按钮缩放和平滑镜头动画
- 点击地图节点或目录中的 L4 数据表打开详情抽屉
- 中文表名、英文表名、业务对象和负责人搜索
- 线上状态、入湖状态筛选
- 按二级主题域分组的卡片/紧凑视图
- 数据表详情抽屉
- 桌面和移动端响应式布局

## 更新数据

当前 `data.js` 为从 Excel 生成的静态数据。Excel 更新后，需要重新生成该文件。
